# Honeydew model training

`Honeydew_Music_Intent_Training.ipynb` — открыть в Google Colab и выполнить по ячейкам.

`honeydew_training.csv` — стартовый формат размеченных запросов. Примеры нужны только для проверки конвейера; их недостаточно для качественной модели. Пополняйте датасет разнообразными реальными формулировками. Целевые поля: `genre`, `mood`, `energy`, `mode`, `instrument`.

Colab обучает символьные TF-IDF + Logistic Regression классификаторы с нуля и экспортирует `honeydew_intent_model.json`. Такой формат позволяет реализовать лёгкий inference в Rust без Python, API-ключа или большой нейросети. Перед интеграцией потребуется написать и протестировать Rust-совместимый загрузчик JSON и вычисление n-грамм/оценок.
